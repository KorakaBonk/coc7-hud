# CoC7 HUD

A hideable investigator HUD at the bottom of the screen for the
[Call of Cthulhu 7th Edition](https://github.com/Miskatonic-Investigative-Society/CoC7-FoundryVTT) system on
Foundry VTT. It shows the portrait, conditions, HP, Magic Points, Sanity and Luck, and opens drawers for
characteristics, skills and combat, all rolled through the system's own dialogs and chat cards. Keepers get a
reduced HUD for a single controlled NPC or creature. Light and dark themes follow Foundry's color scheme.

Requires Foundry VTT v14 and CoC7 8.16 or later.

## Install

In Foundry's **Add-on Modules** tab, choose **Install Module** and paste this manifest URL:

```
https://github.com/KorakaBonk/coc7-hud/releases/latest/download/module.json
```
